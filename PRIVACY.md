## Политика конфиденциальности

> [!NOTE]
> **etCetera** является неофициальным клиентом социальной сети [итд](https://итд.com/). Приложение не связано с администрацией или разработчиками социальной сети итд.
>
> Использование социальной сети итд также регулируется её собственной [Политикой конфиденциальности](https://итд.com/privacy).

### 1. Общие положения

Настоящая Политика конфиденциальности описывает обработку данных при использовании мобильного приложения **etCetera**.

**etCetera не имеет собственных серверов и не передаёт данные пользователей разработчику приложения.** Приложение используется исключительно как клиент для взаимодействия с социальной сетью итд.

### 2. Какие данные обрабатывает приложение

Для обеспечения работы приложения etCetera может обрабатывать данные, связанные с использованием социальной сети, включая:

* данные, необходимые для аутентификации пользователя;
* данные профиля;
* посты и комментарии;
* информацию о лайках и других действиях;
* изображения и другие медиафайлы;
* другие данные, предоставляемые API социальной сети итд.

Объём и содержание этих данных определяются функциональностью социальной сети и действиями пользователя.

### 3. Передача данных социальной сети итд

Для работы приложения данные передаются **непосредственно между устройством пользователя и серверами социальной сети итд**.

Например, при входе в аккаунт введённые пользователем данные для аутентификации передаются серверам итд для выполнения авторизации.

Разработчик etCetera **не получает доступ к логинам, паролям, токенам авторизации, сообщениям, постам или другим данным пользователя**, если иное прямо не указано в данной Политике.

После передачи данных серверам итд их обработка осуществляется социальной сетью итд в соответствии с её [Политикой конфиденциальности](https://итд.com/privacy).

### 4. Локальное хранение данных

Для обеспечения работы и повышения производительности etCetera может хранить некоторые данные непосредственно на устройстве пользователя.

К таким данным могут относиться:

* токены и другие данные авторизации;
* данные профиля;
* кэш постов, комментариев и другой информации;
* кэш изображений и медиафайлов;
* настройки приложения;
* другие временные данные, необходимые для работы приложения.

Эти данные хранятся **локально на устройстве пользователя** и не передаются разработчику etCetera.

Локально сохранённые данные могут быть удалены пользователем посредством очистки данных приложения или удаления приложения, в зависимости от механизмов операционной системы.

### 5. Сбор данных разработчиком

Разработчик etCetera не осуществляет сбор данных пользователей для собственных целей.

Приложение не использует:

* сторонние системы аналитики;
* рекламные SDK;
* системы отслеживания пользователей;
* собственные серверы для хранения пользовательских данных.

Разработчик также не получает идентификаторы устройства или рекламные идентификаторы для целей аналитики, рекламы или отслеживания пользователей.

### 6. Безопасность

Поскольку etCetera не передаёт пользовательские данные собственным серверам разработчика, разработчик не имеет возможности самостоятельно контролировать безопасность данных после их передачи социальной сети итд.

Безопасность данных, передаваемых социальной сети итд, зависит от используемых социальной сетью механизмов защиты и безопасности устройства пользователя.

Пользователю рекомендуется использовать актуальную версию операционной системы, устанавливать приложения только из доверенных источников и не передавать данные авторизации третьим лицам.

### 7. Изменения политики

Настоящая Политика конфиденциальности может периодически обновляться. При внесении существенных изменений новая версия политики будет опубликована вместе с приложением.

### 8. Контакты

По вопросам, связанным с настоящей Политикой конфиденциальности или работой приложения etCetera, пользователь может обратиться к разработчику через контактные данные, указанные на странице приложения.
